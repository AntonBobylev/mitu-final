# mitu-final

TodoList Web-application for MITU (Final Course Project).

---

## Требования для работы приложения
- Node.js (версия 24.x или выше)

---

## Предустановки

1. В папках `backend` и `frontend` есть файлы `.env.example`. Скопируйте их и переименуйте в `.env`:
    - `backend/.env.example` -> `backend/.env`
    - `frontend/.env.example` -> `frontend/.env`

2. Заполните переменные окружения нужными значениями (например, `PORT`, `API_KEY`, `VITE_API_URL`, `VITE_API_KEY`).

3. Установите зависимости в обоих каталогах:
   ```bash
   cd backend && npm install
   cd ../frontend && npm install
   ```

---

## Запуск приложения

### Backend

```bash
cd backend && node server.js
```

### Frontend

```bash
cd frontend && npm run dev
```

### Tests

Запуск тестов фронтенда:
```bash
cd frontend && npm run test
```

Примечание по запуску тестов: <br />
_Интеграционные тесты компонента App вызывают методы API. Для успешного прохождения тестов необходимо, чтобы был запущен сервер backend с корректно настроенными переменными окружения (.env), либо сетевые fetch-запросы в тестах должны быть перехвачены с помощью Mocks (например, через vi.fn() / msw). При выполнении сквозных или интеграционных тестов рекомендуется использовать изолированное тестовое окружение (или тестовую БД/память), чтобы операции создания и очистки записей не затрагивали рабочие данные._

## Документация API

Все запросы к API требуют передачи заголовка авторизации по API-ключу:

#### 1. Получить список всех задач

* Метод: GET
* Адрес: /api/tasks
* Назначение: Возвращает полный список всех созданных задач.
* Заголовки:
  * x-api-key: строка (обязательный)

  Пример успешного ответа (200 OK):
  ```json
  [
    {
      "id": 1,
      "text": "Купить молоко",
      "completed": false
    },
    {
      "id": 2,
      "text": "Сделать домашнее задание",
      "completed": true
    }
  ]
  ```

  Возможные коды ответов:
  * 200 OK — Успешное получение списка
  * 401 Unauthorized — Отсутствует или неверный x-api-key
  * 500 Internal Server Error - Internal Server Error

#### 2. Создать новую задачу

* Метод: POST
* Адрес: /api/tasks
* Назначение: Добавляет новую задачу в список. По умолчанию задача создается со статусом completed: false.
* Заголовки:
    * x-api-key: строка (обязательный)
    * Content-Type: application/json (обязательный)

  Пример тела запроса (JSON):
  ```bash
  {
    "text": "Купить молоко"
  }
  ```
  Валидация входных данных:
  * Поле text обязательное, должно быть строкой и не быть пустым (или состоять только из пробелов).
  
  Пример успешного ответа (201 Created):
  ```json
  {
    "id": 1,
    "text": "Купить молоко",
    "completed": false
  }
  ```

  Возможные коды ответов:
  * 201 Created — Задача успешно создана
  * 400 Bad Request — Текст задачи отсутствует, не является строкой или состоит из одних пробелов
  * 401 Unauthorized — Отсутствует или неверный x-api-key
  * 500 Internal Server Error - Internal Server Error

#### 3. Обновить задачу (текст и/или статус)

* Метод: PUT
* Адрес: /api/tasks/:id
* Назначение: Частично или полностью обновляет существующую задачу по её ID (текст, статус выполнения или оба поля).
* Заголовки:
  * x-api-key: строка (обязательный)
  * Content-Type: application/json (обязательный)
* Параметры URL:
  * id: number — идентификатор задачи.

  Пример тела запроса (Обновление текста и статуса):
  ```json
  {
    "text": "Купить свежее молоко",
    "completed": true
  }
  ```
  
  Пример тела запроса (Только изменение статуса):
  ```json
  {
    "completed": true
  }
  ```
  
  Валидация входных данных:
  * Поле text (если передано): должно быть непустой строкой.
  * Поле completed (если передано): должно быть булевым значением (true или false).
  * В запросе должно быть передано хотя бы одно из разрешенных полей (text или completed).
  
  Пример успешного ответа (200 OK):
  ```json
  {
    "id": 1,
    "text": "Купить свежее молоко",
    "completed": true
  }
  ```
  
  Возможные коды ответов:
  * 200 OK — Задача успешно обновлена
  * 400 Bad Request — Переданы некорректные типы данных или не передан ни один параметр.
  * 401 Unauthorized — Отсутствует или неверный x-api-key
  * 404 Not Found — Задача с указанным ID не найдена
  * 500 Internal Server Error - Internal Server Error

#### 4. Удалить задачу

* Метод: DELETE
* Адрес: /api/tasks/:id
* Назначение: Удаляет существующую задачу по её ID.
* Заголовки:
  * x-api-key: строка (обязательный)
* Параметры URL:
  * id: number — идентификатор задачи.

  Пример успешного ответа (204 No Content):
    * Пустое тело ответа.
  
  Возможные коды ответов:
  * 204 No Content — Задача успешно удалена
  * 401 Unauthorized — Отсутствует или неверный x-api-key
  * 500 Internal Server Error - Internal Server Error
