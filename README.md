# mitu-final

Project for the final part of the course

## Требования для работы приложения
* Node.js выше v24

## Предустановки
В папках backend и frontend есть .env.example<br/>
Их нужно скопировать и переименовать в .env<br/>
После этого надо заполнить их своими значениями. <br/>
Также надо установить зависимости в папках backend и frontend:<br/>
* `cd backend && npm install`
* `cd frontend && npm install`

## Backend
Запуск сервера: `cd backend && node server.js`

## Frontend
Запуск приложения: `cd frontend && npm run dev`

## Tests
Запуск тестов: `cd backend && npm run test`
